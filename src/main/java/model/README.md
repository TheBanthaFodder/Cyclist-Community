# Model Package

## Subpackages
* `model/application` - MVC-facing model classes used by controllers
* `model/race` - race, route, license, registration, result, and category domain classes
* `model/user` - user types plus strategy/context classes
* `model/observer` - shared observer abstractions used by the category flow

## Package Guide
* `model/application`: `AdminModel`, `EntranceModel`, `OrganizerModel`, `RacerModel`
* `model/race`: `Category`, `Race`, `RaceLicense`, `RaceRegistration`, `RaceResult`, `Route`
* `model/user`: `Administrator`, `Organizer`, `Racer`, `User`, `UserContext`, `UserStrategy`
* `model/observer`: `Observer`, `Subject`
